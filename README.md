# Git-Org-Metrics
[![CI](https://github.com/WallyGuzman/Git-Org-Metrics/actions/workflows/ci.yaml/badge.svg)](https://github.com/WallyGuzman/Git-Org-Metrics/actions/workflows/ci.yaml)

Experiment to visualize Git repo metrics in static page. This is my naive attempt to reproduce the excellent work in the [duckdb-dev-dashboard](https://github.com/duckdblabs/duckdb-dev-dashboard) to learn more about GitHub Pages and WASM.

Specifically, I'd like to see if it is possible to do so _without_ relying on an external hosting platform, like Cloudflare. Whether that is possible remains to be seen. There are a few other changes I'd like to make as well.

Note: This repo assumes installation of the Steampipe GitHub plugin.
